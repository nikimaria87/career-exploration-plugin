# NextJobber brand kit

Open `START-HERE.html` after downloading/extracting the full folder. Open `studio/index.html` to edit a poster and export SVG or PNG. The source artwork and templates remain editable in ordinary design tools.

The kit covers all 17 categories in the supplied asset-menu reference. `asset-categories.json` maps each category to its starting file. The main folders contain outlined SVG and PNG logos, profile icons, font files and license, two website templates, two generated mockups, business cards, Facebook covers, Instagram posts and stories, an editable six-slide PowerPoint, logo animation, QR exports, a Word/PDF invoice template, brand settings, a design studio, and support materials.

Replace bracketed contact, presentation, and invoice fields before using the templates. The QR and website buttons point to the current owner-private dashboard. Choose a public destination or review audience access before public campaigns. The Enterprise Chat category is a local support-widget prototype and response library, with no staffed team or message delivery connected.

SVG logo masters use original path lettering rather than the screenshot's font. The reference informed the airy geometric character and two-tone palette. Typography, stroke joins, complete E/B stems, spacing, and the NJ symbol distinguish this artwork.

The DejaVu Sans fonts and their redistribution license are in `fonts/`. The outlined logo does not require a font installation. Business-card PDFs include bleed and use RGB artwork; the print note explains dimensions and printer conversion.

`source/` holds the editable generators and recorded image prompts. The generators were authored for the Codex primary runtime. The PDF and DOCX scripts use ReportLab and python-docx; raster exports use Sharp. The PowerPoint builder requires the Artifact Tool and finalizer supplied with Codex Work. You can edit the actual SVG, HTML, DOCX and PPTX files without running a generator.

The photographic mockups use the built-in image-generation tool. They are illustrative brand concepts. The master logo, exact template layouts, QR modules, and motion frames use the supplied native vector source.
