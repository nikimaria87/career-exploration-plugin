# Brand support response library

## Logo files
Use SVG for scalable artwork and PNG for image uploads. Choose the white version on plum. Use the NJ icon for small profile and app uses.

## Template edits
Open the design studio for an SVG or PNG poster. Open DOCX files in Word and PPTX files in PowerPoint. Install the included font files to match the template typography.

## Contact details
Replace every bracketed field with approved business details before distribution.

## QR destination
The current QR points to a private dashboard. Confirm the intended audience can open the destination before printing.

## Enterprise support setup
Choose a support address, staffing arrangement, and helpdesk provider. Define hours, routing, and response expectations. This kit provides prototype UI and response copy only.
